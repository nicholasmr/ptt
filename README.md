# Polarimetric travel-time tomography model (PTT)

**Code and scripts for reproducing the calculations and plots in [Rathmann (2026, RSPA)](google.com)**

***What is it?*** 📡
- A polarimetric common-mid-point (CMP) framework for ice sheets that accounts for the dielectric anisotropy arising from preferred crystal orientations and preferred bubble shapes in firn, including refractive bending due to density variations.

***What can it do?*** 🧊
- Model travel times along oblique, bending ray paths using a Maxwell–Garnett effective medium formulation coupled to a single stage Herron–Langway density model with a power-law bubble eccentricity profile.
- Solve an inverse problem to robustly recover the fabric eigenvalue profile and bubble close-off depth from a limited set of CMP offsets, even in the presence of noise.
